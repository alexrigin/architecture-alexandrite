## Мотивация

Мониторинг позволяет получить более полное представление о состоянии системы, что предоставляет следующие преимущества:
- обнаружение узких мест, повышение надежности и решение проблем с производительсностью и функциональностью
- сбор бизнес-метрик позволяет получить ценные бизнес-инсайсы, которые способствуют принятию обоснованных стратегических решений
- можно настроить алертинг, которые позволит оперативно реагировать на проблемы.

<br />

## Выбор подхода к мониторингу

RED:
- Requests Rate — частота запросов,
- Errors — ошибки,
- Duration — длительность.

## Метрики для отслеживания

Взаимодействие CRM <-> MES:
- Number of dead-letter-exchange letters in RabbitMQ - количество сообщений, попавших в "мертвую" очередь. позволит просигнализировать о проблемных заказах, которые были отправлены из CRM, но по каким-то причинам не попали в MES
  - labels: topic
- Number of message in flight in RabbitMQ - количество сообщений, находящихся в очереди, но которые еще не были обработаны консьюмером. метрика позволить определить текущее количество заказов, которые были созданы в CRM, но еще не были обработаны в MES.
  - labels: topic

CRM:
- Number of requests (RPS) for CRM API. количество запросов в секунду, отправляемых в интернет магазин. позволяет следить динамикой нагрузки
  - labels: code, method, url
- CPU % for CRM API. Загрузка CPU. позволяет определить есть ли проблемы с производительностью
- Memory Utilisation for CRM API. позволяет отслеживать степень заполнения RAM. можно определить хватает ли памяти, есть ли утечки и т.д.
- Response time (latency) for CRM API. время ответа
  - labels: method, url

MES:
- Number of requests (RPS) for MES API. количество запросов в секунду, отправляемых в интернет магазин
  - labels: code, method, url
- CPU % for MES API. Загрузка CPU. позволяет определить есть ли проблемы с производительностью
- Memory Utilisation for MES API. позволяет отслеживать степень заполнения RAM. можно определить хватает ли памяти, есть ли утечки и т.д.
- Memory Utilisation for MES db instance. позволяет определить производительность БД
- Number of connections for MES db instance. количество запросов в БД. позволяет оценить нагрузку БД
- Size of MES db instance. размер БД. можно настроить алерт
- Response time (latency) for MES API. время ответа
  - labels: method, url

Онлайн-магазин:
- Number of requests (RPS) for internet shop API. количество запросов в секунду, отправляемых в интернет магазин
  - labels: code, method, url
- CPU % for shop API. Загрузка CPU. позволяет определить есть ли проблемы с производительностью.
- Memory Utilisation for shop API. позволяет отслеживать степень заполнения RAM. можно определить хватает ли памяти, есть ли утечки и т.д.
- Memory Utilisation for shop db instance. позволяет определить производительность БД
- Number of connections for shop db instance. количество запросов в БД. позволяет оценить нагрузку БД
- Size of shop db instance. размер БД. можно настроить алерт
- Response time (latency) for shop API. время ответа.
  - labels: method, url

S3 storage:
- Size of S3 storage. позволяет отслеживать степень заполнения s3 bucket-ов 
  - labels: bucket

## План действий

1. Разворачиваем Prometheus
   - в scrape_configs указываем список сервисов для извлечения метрик (shop-api, mes-api, crm-api, shop-db, mes-db)
   - настраиваем алерты
2. Разворачиваем Grafana и подключаем ее к нашему Prometheus
   1. настраиваем дашборды
3. подготавлием нужные сервисы для сбора выбранных метрик
4. собираем метрика и анализируем
