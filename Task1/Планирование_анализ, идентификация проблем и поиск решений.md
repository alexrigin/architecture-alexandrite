## Cуществующие и потенциальные проблемные места:

1. Проблемы с производительностью, надежностью и масштабируемостью:
   -  Каждое приложение работает только на одном инстансе
   -  Каждая база работает только на одном инстансе (и одновременно работает и на запись и на чтение
   -  осутствует кеширование
   -  внешние продавцы могут отправлять много запросов, которые система не успевает обрабатывать. Нет механизма наподобие Backpressure
   -  проблемы mes:
      - долгая обработка расчета стоимости (для сложных моделей может достигать 30 минут)
      - первая страница в MES долго прогружается
2. Проблемы с тестированием и релизным процессом. 
   - возрастающие задержки релизов
   - нет автотестов, все тестирование производится вручную
   - нет нагрузочного тестирования.
3. судя по всему, нет логов и метрик.
4. Организационные проблемы:
   - важный и высоконагруженный сервис mes написан на c#, но есть только один разработчик на c#
   - фронт mes написан на react и есть только один разработчик, который "частично" знает React


## Инициативы, которые необходимы для устранения нежелательных ситуаций. 

1. Настроить мониторинг (+алертинг), логирование и трейсинг.
2. Оптимизация работы MES:
   1. Добавить индексы в БД для оптимизации запросов
   2. Добавить реплики БД, настроенные только для чтения, чтобы снизить нагрузку с единственной БД и повысить отказоустойчивость
   3. Настроить кеширование.
   4. Добавить дополнительные инстансы
3. Написать автотесты
4. Вынести расчет стоимости в отдельный сервис и горизонтально масштабировать в зависимости от нагрузки
5. Реализовать паттер backpressure 
6. Организационные изменения:
   1. нанять как минимум одного автотестера
   2. нанять как минимум одного c# разработчика
   3. нанять как минимум одного фронтендера с экспетизой в React


## Три основных инициативы за ближайшие полгода:
1. Настройка логирования, мониторинга и алертинга. Сейчас непонятно в каком именно месте и что ломается.

3. Добавить для всех аппов доп. инстансы. Это повысит производительность и отказоуйсточивость.
